## OCR 文本说明
OCR 文本按页面划分，每页以 `[Page N]` 标记开头（N 从 1 开始）。
提取字段时，请在 `page_ref` 字段中记录该值所在的页码（整数，如 1, 2, 3）。

## 提取规则
1. 对于每个字段，找到其对应的值。如果找不到该字段，值设为 null。
2. 对每个提取的值给出置信度（0.0~1.0）。
3. 金额字段只提取数字，去掉货币符号和逗号。
4. 日期字段统一格式为 YYYY-MM-DD。
5. 如果同一字段有多个候选值，选最佳匹配。

## 输出格式
以 JSON 格式返回，结构如下：
```json
{
  "fields": [
    {"code": "字段编码", "value": "提取的值", "confidence": 0.95, "page_ref": 1}
  ],
  "summary": "文档摘要",
  "document_type": "文档类型"
}
```
