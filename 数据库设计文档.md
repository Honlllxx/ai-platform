# 面向复杂版面的商业单据自动化录入平台 — 数据库设计文档

## 设计原则

- 所有表统一使用 `BIGSERIAL` 主键，与前端 `number` 类型对齐
- 时间字段统一 `TIMESTAMPTZ`，Java 侧用 `LocalDateTime` 映射
- 状态类字段使用 `VARCHAR` 枚举值（不用 PostgreSQL ENUM，方便扩展）
- JSONB 存储半结构化数据（版面区域、OCR 条目、表格、StateGraph 等）
- 软删除用 `deleted_at` 字段（关键业务表），日志类表不做软删除
- 统一审计字段：`created_at`、`updated_at`（业务表），日志表用 `create_time`

## 1. RBAC 权限体系（5 张表）

### 1.1 `users` — 用户表

```sql
CREATE TABLE users (
    id              BIGSERIAL       PRIMARY KEY,
    username        VARCHAR(50)     NOT NULL UNIQUE,
    password        VARCHAR(255)    NOT NULL,               -- BCrypt 哈希
    nickname        VARCHAR(100),
    email           VARCHAR(100),
    phone           VARCHAR(30),
    avatar          VARCHAR(500),
    status          SMALLINT        NOT NULL DEFAULT 1,     -- 1=启用, 0=禁用
    created_at      TIMESTAMPTZ     NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ     NOT NULL DEFAULT NOW(),
    deleted_at      TIMESTAMPTZ                              -- 软删除
);

CREATE INDEX idx_users_status ON users(status);
CREATE INDEX idx_users_deleted_at ON users(deleted_at);
```

**对应前端接口**: `UserInfo` (`api/user.ts`)
**注意**: `roleIds`/`roleNames` 不存 users 表，通过关联查询 `user_roles` 得出。

### 1.2 `roles` — 角色表

```sql
CREATE TABLE roles (
    id              BIGSERIAL       PRIMARY KEY,
    name            VARCHAR(100)    NOT NULL,               -- "超级管理员"
    code            VARCHAR(50)     NOT NULL UNIQUE,        -- "admin"
    description     VARCHAR(500),
    status          SMALLINT        NOT NULL DEFAULT 1,     -- 1=启用, 0=禁用
    created_at      TIMESTAMPTZ     NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ     NOT NULL DEFAULT NOW(),
    deleted_at      TIMESTAMPTZ
);

CREATE INDEX idx_roles_code ON roles(code);
```

**对应前端接口**: `RoleInfo` (`api/role.ts`)
**注意**: `permissionIds` 和 `userCount` 不存 roles 表，前者查 `role_permissions`，后者查 `user_roles` 聚合。

### 1.3 `permissions` — 权限表

```sql
CREATE TABLE permissions (
    id              BIGSERIAL       PRIMARY KEY,
    name            VARCHAR(100)    NOT NULL,               -- "用户管理"
    code            VARCHAR(100)    NOT NULL UNIQUE,        -- "user:list"
    type            VARCHAR(20)     NOT NULL DEFAULT 'menu',-- 'menu'|'button'|'api'
    parent_id       BIGINT          REFERENCES permissions(id),
    path            VARCHAR(200),                           -- "/system/users"
    icon            VARCHAR(50),                            -- Element Plus 图标名
    sort            INT             NOT NULL DEFAULT 0,
    status          SMALLINT        NOT NULL DEFAULT 1,     -- 1=启用, 0=禁用
    created_at      TIMESTAMPTZ     NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ     NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_permissions_parent ON permissions(parent_id);
CREATE INDEX idx_permissions_type ON permissions(type);
```

**对应前端接口**: `PermissionInfo` (`api/permission.ts`)
**说明**: 树形结构通过 `parent_id` 自引用实现，`children` 在应用层递归组装。38 条种子数据见下方。

### 1.4 `user_roles` — 用户-角色关联

```sql
CREATE TABLE user_roles (
    id              BIGSERIAL       PRIMARY KEY,
    user_id         BIGINT          NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    role_id         BIGINT          NOT NULL REFERENCES roles(id) ON DELETE CASCADE,
    created_at      TIMESTAMPTZ     NOT NULL DEFAULT NOW(),
    UNIQUE(user_id, role_id)
);

CREATE INDEX idx_user_roles_user ON user_roles(user_id);
CREATE INDEX idx_user_roles_role ON user_roles(role_id);
```

### 1.5 `role_permissions` — 角色-权限关联

```sql
CREATE TABLE role_permissions (
    id              BIGSERIAL       PRIMARY KEY,
    role_id         BIGINT          NOT NULL REFERENCES roles(id) ON DELETE CASCADE,
    permission_id   BIGINT          NOT NULL REFERENCES permissions(id) ON DELETE CASCADE,
    created_at      TIMESTAMPTZ     NOT NULL DEFAULT NOW(),
    UNIQUE(role_id, permission_id)
);

CREATE INDEX idx_role_perm_role ON role_permissions(role_id);
CREATE INDEX idx_role_perm_perm ON role_permissions(permission_id);
```

## 2. 文档处理流水线（8 张表）

### 2.1 `documents` — 文档表

```sql
CREATE TABLE documents (
    id              BIGSERIAL       PRIMARY KEY,
    file_name       VARCHAR(500)    NOT NULL,
    file_type       VARCHAR(20)     NOT NULL,               -- 'pdf'|'jpg'|'png'|'word'
    file_size       BIGINT          NOT NULL,               -- bytes
    file_url        VARCHAR(1000)   NOT NULL,               -- MinIO object URL
    page_count      INT,
    upload_user_id  BIGINT          REFERENCES users(id),
    status          VARCHAR(30)     NOT NULL DEFAULT 'pending',
                    -- 'pending'|'preprocessing'|'completed'|'failed'
    error_message   TEXT,
    created_at      TIMESTAMPTZ     NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ     NOT NULL DEFAULT NOW(),
    deleted_at      TIMESTAMPTZ
);

CREATE INDEX idx_documents_status ON documents(status);
CREATE INDEX idx_documents_file_type ON documents(file_type);
CREATE INDEX idx_documents_upload_user ON documents(upload_user_id);
CREATE INDEX idx_documents_created_at ON documents(created_at);
```

**对应前端接口**: `DocumentItem` (`api/document.ts`)

### 2.2 `document_layouts` — 版面分析结果

```sql
CREATE TABLE document_layouts (
    id              BIGSERIAL       PRIMARY KEY,
    document_id     BIGINT          NOT NULL REFERENCES documents(id) ON DELETE CASCADE UNIQUE,
    image_url       VARCHAR(1000),                          -- 标注后的版面图
    regions         JSONB           NOT NULL DEFAULT '[]',  -- 区域列表
    -- regions[i]: { id, label, x, y, width, height, color, type, confidence }
    confidence      DOUBLE PRECISION,
    created_at      TIMESTAMPTZ     NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_doc_layouts_doc ON document_layouts(document_id);
```

**对应前端接口**: `GET /documents/:id/layout` 的返回值

### 2.3 `document_ocr` — OCR 识别结果

```sql
CREATE TABLE document_ocr (
    id              BIGSERIAL       PRIMARY KEY,
    document_id     BIGINT          NOT NULL REFERENCES documents(id) ON DELETE CASCADE UNIQUE,
    total_chars     INT,
    avg_confidence  DOUBLE PRECISION,
    language        VARCHAR(20)     DEFAULT 'ch',
    entries         JSONB           NOT NULL DEFAULT '[]',  -- OCR 条目列表
    -- entries[i]: { id, text, confidence, bbox: {x,y,w,h} }
    created_at      TIMESTAMPTZ     NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_doc_ocr_doc ON document_ocr(document_id);
```

**对应前端接口**: `GET /documents/:id/ocr` 的返回值

### 2.4 `document_tables` — 表格提取结果

```sql
CREATE TABLE document_tables (
    id              BIGSERIAL       PRIMARY KEY,
    document_id     BIGINT          NOT NULL REFERENCES documents(id) ON DELETE CASCADE UNIQUE,
    confidence      DOUBLE PRECISION,
    original_table  JSONB           NOT NULL DEFAULT '{}',  -- { headers, rows }
    extracted_table JSONB           NOT NULL DEFAULT '{}',  -- { headers, rows }
    created_at      TIMESTAMPTZ     NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_doc_tables_doc ON document_tables(document_id);
```

**对应前端接口**: `GET /documents/:id/table` 的返回值

### 2.5 `pipelines` — 处理流水线

```sql
CREATE TABLE pipelines (
    id              BIGSERIAL       PRIMARY KEY,
    document_id     BIGINT          NOT NULL REFERENCES documents(id) ON DELETE CASCADE,
    task_id         VARCHAR(36)     NOT NULL UNIQUE,        -- UUID, RocketMQ 消息关联
    status          VARCHAR(20)     NOT NULL DEFAULT 'pending',
                    -- 'pending'|'running'|'completed'|'failed'
    current_step    VARCHAR(50),                            -- 当前步骤名
    total_steps     INT             NOT NULL DEFAULT 6,
    completed_steps INT             NOT NULL DEFAULT 0,
    duration        DOUBLE PRECISION,                       -- seconds
    state_graph     JSONB,                                  -- { nodes[], edges[] } 持久化 StateGraph
    error_message   TEXT,
    started_at      TIMESTAMPTZ,
    finished_at     TIMESTAMPTZ,
    created_at      TIMESTAMPTZ     NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ     NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_pipelines_doc ON pipelines(document_id);
CREATE INDEX idx_pipelines_status ON pipelines(status);
CREATE INDEX idx_pipelines_task_id ON pipelines(task_id);
```

**对应前端接口**: `PipelineItem` / `PipelineDetail` (`api/pipeline.ts`)
**注意**: `documentName` 通过 JOIN `documents.file_name` 获得；`stateGraph` 直接存 JSONB 避免过多子表。

### 2.6 `extraction_results` — 字段提取结果

```sql
CREATE TABLE extraction_results (
    id              BIGSERIAL       PRIMARY KEY,
    pipeline_id     BIGINT          NOT NULL REFERENCES pipelines(id) ON DELETE CASCADE,
    field_name      VARCHAR(100)    NOT NULL,
    field_code      VARCHAR(100)    NOT NULL,
    extracted_value TEXT,
    confidence      DOUBLE PRECISION NOT NULL DEFAULT 0,    -- 0-1
    status          VARCHAR(20)     NOT NULL DEFAULT 'uncertain',
                    -- 'verified'|'uncertain'|'rejected'
    page_ref        INT,
    created_at      TIMESTAMPTZ     NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_extraction_pipeline ON extraction_results(pipeline_id);
CREATE INDEX idx_extraction_status ON extraction_results(status);
```

**对应前端接口**: `ExtractionField` (`api/pipeline.ts`)

### 2.7 `validation_results` — 校验报告

```sql
CREATE TABLE validation_results (
    id              BIGSERIAL       PRIMARY KEY,
    pipeline_id     BIGINT          NOT NULL REFERENCES pipelines(id) ON DELETE CASCADE,
    rule            VARCHAR(200)    NOT NULL,
    field_name      VARCHAR(100),
    severity        VARCHAR(20)     NOT NULL DEFAULT 'info',
                    -- 'error'|'warning'|'info'
    message         TEXT            NOT NULL,
    suggestion      TEXT,
    created_at      TIMESTAMPTZ     NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_validation_pipeline ON validation_results(pipeline_id);
```

**对应前端接口**: `ValidationItem` (`api/pipeline.ts`)

### 2.8 `reflection_results` — 反思纠正记录

```sql
CREATE TABLE reflection_results (
    id              BIGSERIAL       PRIMARY KEY,
    pipeline_id     BIGINT          NOT NULL REFERENCES pipelines(id) ON DELETE CASCADE,
    field_name      VARCHAR(100)    NOT NULL,
    before_value    TEXT,
    after_value     TEXT,

CREATE INDEX idx_reflection_pipeline ON reflection_results(pipeline_id);
```

## 5. 日志审计（2 张表）

### 5.1 `operation_logs` — 操作日志

```sql
CREATE TABLE operation_logs (
    id              BIGSERIAL       PRIMARY KEY,
    user_id         BIGINT          REFERENCES users(id),

    description     TEXT,
    request_params  TEXT,                                   -- JSON string
    response_result TEXT,                                   -- JSON string (truncated)
    ip              VARCHAR(50),
    duration        INT,                                    -- milliseconds
    status          VARCHAR(10)     NOT NULL DEFAULT 'success',
                    -- 'success'|'fail'
    created_at      TIMESTAMPTZ     NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_op_logs_user ON operation_logs(user_id);
CREATE INDEX idx_op_logs_type ON operation_logs(operation_type);
CREATE INDEX idx_op_logs_module ON operation_logs(module);
CREATE INDEX idx_op_logs_created_at ON operation_logs(created_at);
```
